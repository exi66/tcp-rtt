# tcp-rtt

Приложение для мониторинга задержки (RTT) до игрового сервера на основе перехвата TCP трафика. В отличие от обычного ping (ICMP), измеряет реальное время отклика по тому же пути, по которому идут игровые данные.

## Как работает

Приложение перехватывает TCP пакеты на выбранном сетевом интерфейсе. Когда клиент отправляет пакет с данными, фиксируется время отправки и ожидаемый ACK-номер. Когда сервер присылает подтверждение (ACK), вычисляется разница — это и есть RTT.

- Каждое TCP-соединение отслеживается отдельно.
- Для времени используются метки захвата Npcap, а не время обработки пакета.
- Повторно отправленные сегменты не измеряются (алгоритм Карна).
- Если один ACK подтверждает несколько сегментов, учитывается только самый новый.
- Сегменты без подтверждения дольше 1 секунды попадают в **Timeout %**.
- Значения ниже **Min RTT** считаются шумом и не попадают ни на график, ни в статистику.

## Использование

1. Установите [Npcap](https://npcap.com). Если при установке выбран режим «только для администраторов», запускайте приложение от имени администратора.
2. Укажите адрес сервера (`203.0.113.10`) или подсеть (`203.0.113.0/24`) и порт.
3. Выберите сетевой интерфейс и нажмите **Start**.

Кнопка **Overlay** переключает окно в режим «поверх всех окон» без рамки; окно можно перетаскивать мышью. Введённые настройки сохраняются в `%APPDATA%\TcpRtt\settings.json`.

## Сборка

```sh
dotnet build TcpRtt.slnx
dotnet test TcpRtt.slnx
dotnet publish src/TcpRtt -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

## Релизы

При пуше тега вида `v1.2.3` GitHub Actions прогоняет тесты, собирает single-file `.exe` для `win-x64` и `win-x86` и публикует их в GitHub Release. Теги с суффиксом (`v1.3.0-beta`) публикуются как pre-release.

```sh
git tag v1.0.0
git push origin v1.0.0
```

## Структура

- `src/TcpRtt/Core` — логика без UI: сопоставление сегментов и ACK, парсинг адресов, статистика
- `src/TcpRtt/Capture` — захват пакетов через SharpPcap
- `tests/TcpRtt.Tests` — юнит-тесты

## Стек

- **.NET 10 / C# / Windows Forms** — UI и основная логика
- **SharpPcap** — перехват сетевых пакетов (требует Npcap)
- **PacketDotNet** — парсинг IP/TCP пакетов
- **ScottPlot** — отображение графика задержки в реальном времени
